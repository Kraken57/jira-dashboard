# How to Run

## Prerequisites

- Node.js 18+
- npm

## Install dependencies

```bash
npm install
```

## Run in development

```bash
npm run dev
```

Then open http://localhost:3000

## Build for production

```bash
npm run build
```

## Start production server

```bash
npm start
```

## What you'll see

- Pod filter dropdown at top
- Sprint timeline below it
- Tab bar (Executive Summary active by default)
- 4 metric cards (Done Ratio, Carry Over, Velocity, Predictability)
- Velocity grid: 6 story-point boxes + 4 histogram charts
- Click tabs to switch views (Pod View / Developer View show placeholder text)
